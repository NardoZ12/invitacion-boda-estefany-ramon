# 🚀 Quick Start - Comienza Ahora

Guía rápida para subir tu invitación y compartir enlaces en 5 minutos.

---

## 📋 Paso 1: Elegir una Plataforma de Hosting

### Opción A: GitHub Pages (Recomendado - GRATIS)

**Ventajas:**
- Totalmente gratis
- Enlace permanente y profesional
- Fácil de actualizar

**Pasos:**

1. **Si el repositorio ya existe** (como en este caso):
   - Ve a tu repositorio en GitHub
   - Click en "Settings" → "Pages"
   - Bajo "Build and deployment" selecciona:
     - Source: "Deploy from a branch"
     - Branch: Selecciona tu rama principal (ej: `main`)
   - Click "Save"

2. **Espera 1-2 minutos** y tu sitio estará en:
   ```
   https://tu-usuario.github.io/invitacion-boda-estefany-ramon/index.html
   ```

3. **Verifica que funciona:**
   - Abre la URL en el navegador
   - Haz clic en "Abrir Invitación"
   - Debería sonar la música

---

### Opción B: Netlify (GRATIS - Alternativa Rápida)

1. Ve a https://www.netlify.com
2. Crea una cuenta (con GitHub es rápido)
3. Click en "Add new site" → "Deploy manually"
4. Arrastra tu carpeta con `index.html`
5. **¡Listo!** Tu URL será algo como: `tu-sitio-123.netlify.app`

## 💬 Paso 4: Compartir por WhatsApp

### Opción A: Copiar Enlace Simple
1. Copia el enlace personalizado (ej: `https://github.com/...?guest=rosa`)
2. Abre WhatsApp
3. Selecciona un contacto o grupo
4. Pega el enlace
5. Añade un mensaje:

```
¡Hola Rosa! 💍

Nos encantaría que nos acompañes en nuestra boda.

👇 Aquí está tu invitación:
https://TU-DOMINIO.com/index.html?guest=rosa

¡Gracias por ser parte de nuestro gran día!

Estefany & Ramón ✨
```

## 🔄 Actualizar la Página Después de Publicar

**Si necesitas cambiar algo tras publicar:**

1. Abre `index.html` en un editor
2. Haz los cambios (nombres, colores, música, etc)
3. Guarda el archivo
4. Sube nuevamente a tu hosting
5. La página se actualizará automáticamente (puede tardar 1-5 minutos)

## 🎨 Personalizaciones Rápidas (Opcional)

### Cambiar Colores en 1 Minuto

Línea ~8 en `index.html`:
```css
--color-accent: #d4af37;    /* Cambiar este color */
```

Usa cualquier color hex: https://htmlcolorcodes.com/

### Cambiar Música en 1 Minuto

Línea ~515 en `index.html`:
```javascript
<source src="NUEVA-URL-MUSICA.mp3">
```

Busca música libre en: https://pixabay.com/es/music/

### Cambiar Frase Romántica en 1 Minuto

Línea ~269 en `index.html`:
```html
<p>"Tu nueva frase"</p>
```
