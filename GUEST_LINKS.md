# Enlaces de Invitación Personalizada - Boda Estefany & Ramón

## 📋 Instrucciones de Uso

Cada enlace abajo corresponde a un grupo de invitados específico. El parámetro `?guest=ID` en la URL carga automáticamente:
- El nombre personalizado del/los invitado(s)
- La cantidad exacta de pases reservados
- Un mensaje personalizado en WhatsApp para RSVP

**Nota:** Los invitados pueden copiar y compartir el enlace dentro de su grupo familiar.

## 📝 Cómo Reemplazar la URL

1. **Reemplaza `tudominio.com`** con tu dominio real o el hosting donde subas el archivo
2. **Copia el enlace completo** y envíalo a los invitados por WhatsApp, email o SMS
3. **Cada invitado verá:**
   - Su nombre personalizado
   - Sus pases reservados
   - El contador regresivo al evento
   - La música de fondo (puede activar/pausar)
   - Botón para confirmar asistencia por WhatsApp

## 🔧 Instrucciones de Hosting

### Opción 1: GitHub Pages (Gratuito)
1. Sube el archivo `index.html` a un repositorio
2. Activa GitHub Pages en Settings
3. Tu URL será: `https://tu-usuario.github.io/nombre-repo/index.html?guest=ID`

### Opción 2: Netlify (Gratuito)
1. Arrastra `index.html` a Netlify
2. Obtén tu URL automáticamente
3. Añade los parámetros: `tu-sitio.netlify.app/index.html?guest=ID`

### Opción 3: Tu Propio Servidor
1. Sube `index.html` a tu servidor
2. Usa tu dominio + parámetros
